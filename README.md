# MasterCel Pricing

Sistema web para calcular los precios de venta de pantallas y repuestos de celulares a partir del precio costo, aplicando porcentajes para cliente y mayorista, con historial y estadísticas.

> 🚧 Proyecto en desarrollo.

## Funcionalidades previstas

- Cálculo de precios para pantallas y repuestos (cliente y mayorista, con y sin garantía)
- Registro de proveedores
- Historial de consultas con búsqueda y actualización
- Estadísticas de los productos más vendidos por mes y año
- Inicio de sesión con JWT

## Stack

**Backend:** Java, Spring Boot, Spring Security, JWT, MySQL
**Frontend:** React, TypeScript, Tailwind CSS, shadcn/ui, React Router, Axios

## Estructura

- `backend/`: API REST (Spring Boot)
- `frontend/`: interfaz web (React)
